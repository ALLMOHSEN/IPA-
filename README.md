# مجرة فوتو: نسخة iOS (iPad / iPhone)

نفس الموقع تماماً (`GalaxyPhoto/Resources/index.html` هو نفس ملف نسخة أندرويد بلا أي تغيير) داخل تطبيق WKWebView بملء الشاشة.

## البناء (يحتاج جهاز Mac)
1. ثبّت Xcode من App Store، ثم في الطرفية: `brew install xcodegen`
2. داخل هذا المجلد: `xcodegen generate` (ينشئ `GalaxyPhoto.xcodeproj`)
3. افتح `GalaxyPhoto.xcodeproj`، واختر Target ثم Signing & Capabilities ثم Team (حساب Apple ID مجاني يكفي للتجربة، وتنتهي صلاحية التثبيت بعد 7 أيام. للتثبيت الدائم يلزم حساب مطوّر مدفوع).
4. وصّل الـ iPad واختره في أعلى Xcode، ثم اضغط Run.

## البناء على GitHub (بدون Mac)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد (يجب أن يكون `project.yml` في جذر المستودع).
2. تبويب Actions ثم Build iOS IPA ثم Run workflow.
3. بعد الانتهاء حمّل `GalaxyPhoto-unsigned-ipa` من أسفل صفحة التشغيل، وفيه `GalaxyPhoto.ipa`.
4. الملف غير موقّع، ويلزم توقيعه بحسابك عند التثبيت: برنامج Sideloadly (ويندوز أو ماك) أو AltStore، مع Apple ID مجاني (يعمل 7 أيام ثم يُعاد التثبيت). التثبيت الدائم أو TestFlight يحتاج حساب مطوّر مدفوع.

## الطباعة (AirPrint)
- أول مرة: اضغط مطولاً على الشعار في الشاشة الرئيسية لمدة 3 ثوانٍ، واختر طابعة Canon SELPHY من القائمة. تُحفظ الطابعة.
- بعد ذلك تُطبع الصورة مباشرة بدون أي نافذة. إن لم تتوفر الطابعة تظهر شاشة الطباعة العادية.
- عدد النسخ (حتى 4) يُرسل كنسخ متعددة، والمقاس 4×6 أو أقرب ورق تعرضه الطابعة.

## رمز QR
نفس آلية أندرويد: نسخة مؤقتة تُرفع إلى file.io وتُحذف بعد أول تحميل أو بعد ساعة، ولا يحتفظ الجهاز بأي نسخة. يحتاج الجهاز إلى إنترنت وقت التصوير.

## وضع الكيوسك
فعّل Guided Access: الإعدادات ثم تسهيلات الاستخدام ثم Guided Access، ثم اضغط زر الجانب ثلاث مرات داخل التطبيق لتثبيته.
